## 🚀 How to Use

### Step 1: First-Time Setup
```bash
cd _Scripts
python setup_and_organize.py
```

### Step 2: Download Papers
**Option A — Interactive (Windows):**
```
Double-click: _Scripts\RUN_DOWNLOADER.bat
```

**Option B — Command Line:**
```bash
# Download everything
python _Scripts/pyq_downloader.py --exam ALL

# Download specific exam
python _Scripts/pyq_downloader.py --exam JEE
python _Scripts/pyq_downloader.py --exam NEET
python _Scripts/pyq_downloader.py --exam UPSC
python _Scripts/pyq_downloader.py --exam CA
python _Scripts/pyq_downloader.py --exam CBSE --class 10
python _Scripts/pyq_downloader.py --exam CBSE --class 12
python _Scripts/pyq_downloader.py --exam SSC
python _Scripts/pyq_downloader.py --exam Banking

# Scrape from official websites
python _Scripts/pyq_scraper.py --all
python _Scripts/pyq_scraper.py --source cbse_official
python _Scripts/pyq_scraper.py --source upsc_official
python _Scripts/pyq_scraper.py --source icai_official
python _Scripts/pyq_scraper.py --source nta_official
```

### Step 3: Organize & Index
```bash
python _Scripts/pyq_organizer.py --all
```

## ⚠️ Important Notes

1. **Network Required**: The downloader scripts require internet access to fetch papers.
2. **Respect Rate Limits**: Scripts include delays between requests (0.3–0.5s) to be respectful to servers.
3. **Official Sources Only**: All papers are fetched from official government/examining body websites.
4. **Storage**: A complete collection from 2000–2026 may require 10–50 GB of storage.
5. **Re-run Safe**: Scripts skip already-downloaded files, so you can re-run safely.

## 📊 Naming Convention

Files are named as:
```

```

Examples:
- `JEE_Advanced_2023_Paper_1.pdf`
- `NEET_2024_QP.pdf`
- `UPSC_CSE_Prelims_GS1_2023.pdf`
- `CBSE_12_Mathematics_2024_Delhi.pdf`
